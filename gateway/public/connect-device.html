Yapay zekâna bağla

Kurulum ekranındaki (terminal ya da Windows uygulaması) bağlantı birkaç saniye içinde tamamlanır. Sonra bu MCP adresini yapay zekâ istemcine ekle:

  1. Claude: Settings → Connectors → Add custom connector. Adı WECOMMANDER, URL yukarıdaki adres. Connect'e bas ve WECOMMANDER hesabınla izin ver.
  2. ChatGPT: Settings → Connectors bölümünde özel MCP bağlayıcısı oluştur (planına göre Developer mode gerekebilir). Aynı URL'yi gir, kimlik doğrulama olarak OAuth seç.
  3. Diğer MCP istemcileri: uzak HTTP MCP sunucusu olarak aynı URL'yi ekle.

Cihazın güven seviyesini ve izinli komutları Cihazlar sayfasından yönetebilirsin.

## English (en-US)

**Product name:** WECOMMANDER

**Short description**
SSH client, server management and a secure MCP server for AI, in one Windows app.

**Description**
WECOMMANDER is a desktop SSH client and server management app. Connect to your servers with tabbed and split terminals, move files with drag-and-drop SFTP, open local, remote and SOCKS tunnels, and see what fills a server's disk and clean it safely.

On Windows, the WECOMMANDER Dock sits on a screen edge like the taskbar, with live CPU, memory and disk charts for your server; Task Manager, Tasks, Terminal and approvals open as panels from it. Prefer windows? Switch to Classic mode.

WECOMMANDER also connects AI assistants such as Claude, ChatGPT and Cursor to your machines with one MCP address. Every risky step (running a command, deleting files, restarting a service) waits for your one-time approval, and every action is in the audit log. With Hybrid Access you can share SSH servers that have no agent through this computer; your keys never leave it.

The SSH client works fully without AI and without an account.

**Product features**
- Tabbed and split SSH terminals, saved servers with groups
- Drag-and-drop SFTP file manager
- Local, remote and SOCKS tunnels, jump hosts
- SSH agent and FIDO2 hardware key sign-in
- Telnet, serial ports and Mosh
- Snippets, autocomplete, session logs and terminal themes
- Disk analysis and safe cleanup, including Docker and rootless Docker
- Processes and zombie process fixes
- WECOMMANDER Dock with live server charts, or Classic mode
- Task Manager for this computer
- Scheduled tasks, systemd timers, cron and Windows tasks
- End-to-end encrypted sync of servers, keys and snippets
- One MCP address for Claude, ChatGPT and Cursor
- One-time approvals and a full audit log
- Hybrid Access: AI for SSH servers without an agent
- English, Turkish, German, French, Spanish and Brazilian Portuguese

**Search terms**
SSH client, SFTP, terminal, server management, MCP, AI, DevOps

**What's new in this version**
Version 1.0: Dock mode and Classic mode, the Windows taskbar look, Hybrid Access for SSH servers without an agent, new icons and a short what's-new note after every update.

# WebRising Commender

Secure, persistent remote computer control for AI clients through MCP.

> Status: active development. The project is being built as a self-hostable, SaaS-ready control plane + native agent.

Core goals:
- resilient outbound agent connection with automatic reconnect
- remote terminal, filesystem and process control
- multi-device routing
- explicit approval policies for risky actions
- audit logging and secret redaction
- self-hosted deployment with no paid infrastructure dependency
- cloud/SaaS architecture without locking out self-hosted users
